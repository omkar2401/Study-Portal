# Study Material and Quiz Portal

## Project Overview

The Study Material and Quiz Portal is a web-based application developed using Python Flask, SQLite, HTML, CSS, and JavaScript. It provides a platform for students to access study materials and practice multiple-choice questions (MCQs).

## Features

- Admin login and study-material management
- Upload and manage PDF study materials
- Student registration and login
- MCQ practice and assessment
- SQLite database integration
- User-friendly web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal in your web browser.

## Purpose

The purpose of this project is to simplify access to digital study materials and provide students with a convenient platform for MCQ-based practice.
